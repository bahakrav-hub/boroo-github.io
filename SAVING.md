# 📦 Система сохранения данных

## Как работает сохранение

### 1. Локальное хранилище (localStorage)
Все изменения автоматически сохраняются в браузере:
- ✅ Текстовый контент (все редактируемые поля)
- ✅ Загруженные фото и видео (в формате base64)
- ✅ Записи на стене памяти
- ✅ Настройки GitHub интеграции
- ✅ Учётные данные администратора

**Ограничения:**
- Размер localStorage: ~5-10 МБ
- Данные хранятся только в одном браузере
- При очистке кэша браузера данные удаляются

### 2. Автоматическая синхронизация с GitHub
Если настроена GitHub интеграция:
- ✅ При каждом изменении контента данные отправляются в GitHub
- ✅ При загрузке медиафайлов данные отправляются в GitHub
- ✅ Данные хранятся в файле `data/site-content.json` в репозитории

**Преимущества:**
- Данные хранятся в облаке (GitHub)
- Можно синхронизировать между устройствами
- История изменений сохраняется в Git
- Резервная копия всегда доступна

### 3. Ручное сохранение
Кнопка **"💾 Сохранить всё"** (в правом верхнем углу для админа):
- Немедленно сохраняет все изменения в localStorage
- Синхронизирует данные с GitHub (если настроено)
- Показывает уведомление об успешном сохранении

## Рекомендации

### Для надёжного хранения данных:

1. **Настройте GitHub интеграцию:**
   - Создайте репозиторий на GitHub
   - Получите Personal Access Token
   - Укажите настройки в панели администратора → вкладка "🐙 GitHub"
   - Нажмите "💾 Сохранить настройки"

2. **Регулярно делайте резервные копии:**
   - Панель администратора → вкладка "💾 Данные"
   - Нажмите "📥 Экспорт данных (JSON)"
   - Сохраните файл в надёжном месте

3. **Используйте кнопку "💾 Сохранить всё":**
   - После внесения важных изменений
   - Перед закрытием браузера
   - Для гарантии синхронизации с GitHub

## Что сохраняется

### Контент сайта:
- Все тексты (имя героя, цитаты, описания)
- Награды и их список
- События таймлайна
- Статистика
- Записи на стене памяти

### Медиафайлы:
- Фотографии (JPG, PNG, WebP, GIF)
- Видео (MP4, WebM)
- Максимальный размер: 5 МБ на файл

### Настройки:
- Учётные данные администратора
- Конфигурация GitHub
- Все изменения контента

## Восстановление данных

### Из localStorage:
Данные автоматически загружаются при открытии сайта.

### Из GitHub:
1. Панель администратора → вкладка "🐙 GitHub"
2. Нажмите "↓ Загрузить из GitHub"
3. Данные восстановятся из репозитория

### Из резервной копии:
1. Панель администратора → вкладка "💾 Данные"
2. Нажмите "📤 Импорт данных (JSON)"
3. Выберите файл резервной копии

## Проблемы и решения

### Данные пропали после очистки кэша:
**Решение:** Восстановите из GitHub или резервной копии

### Медиафайлы не загружаются:
**Причины:**
- Файл слишком большой (>5 МБ)
- Неподдерживаемый формат
- Недостаточно места в localStorage

**Решение:**
- Сожмите изображение перед загрузкой
- Используйте поддерживаемые форматы
- Настройте GitHub интеграцию для хранения в облаке

### Изменения не синхронизируются с GitHub:
**Причины:**
- Не настроена GitHub интеграция
- Неверный токен
- Нет доступа к интернету

**Решение:**
- Проверьте настройки GitHub в панели администратора
- Убедитесь что токен действителен
- Проверьте подключение к интернету

## Технические детали

### Структура данных:
```json
{
  "content": { ... },      // Весь контент сайта
  "media": [ ... ],        // Загруженные медиафайлы (base64)
  "memories": [ ... ],     // Записи на стене памяти
  "exportedAt": "...",     // Дата экспорта
  "version": "1.0"         // Версия формата
}
```

### Ключи localStorage:
- `memorial_auth` - учётные данные
- `memorial_content` - контент сайта
- `memorial_media` - медиафайлы
- `memorial_memories` - записи памяти
- `memorial_github_config` - настройки GitHub

### GitHub интеграция:
- Файл: `data/site-content.json`
- Ветка: настраивается (по умолчанию `main`)
- Формат: JSON с base64 медиафайлами

## Безопасность

- ✅ Пароли хешируются (SHA-256 + salt)
- ✅ GitHub токены хранятся в localStorage (рекомендуется использовать токены с ограниченными правами)
- ✅ Все пользовательские вводы валидируются и санитизируются
- ✅ Защита от XSS и инъекций

## Поддержка

Если возникли проблемы:
1. Проверьте консоль браузера (F12) на наличие ошибок
2. Убедитесь что браузер поддерживает localStorage
3. Проверьте настройки GitHub интеграции
4. Попробуйте восстановить данные из резервной копии
